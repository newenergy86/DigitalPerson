# Реестр документов DigitalPerson

**Документ:** DOC-010-DOCUMENT-REGISTRY

**Версия:** 1.0.0

**Статус:** Active*

> *Статус Active вступает в силу после публикации настоящего документа в официальном репозитории проекта.*

**Основание:**
- DOC-000-CONST
- DOC-110-CHARTER

---

# 1. Общие положения

Настоящий документ определяет единый официальный Реестр документов проекта DigitalPerson.

Реестр является единственным официальным источником информации о документации проекта.

---

# 2. Назначение

Реестр предназначен для:

- ведения перечня документов проекта;
- идентификации документов;
- классификации документов по типам;
- фиксации статуса документов;
- фиксации текущих версий документов;
- обеспечения прослеживаемости документации.

# 4. Типы документов

В проекте используются следующие типы документов.

**Governance** — нормативные документы, определяющие правила управления проектом.

**Role** — документы, описывающие роли проекта.

В дальнейшем перечень типов может быть расширен решением Совета (например: Specification, ADR, RFC, Research и другие).

---

# 5. Правила ведения Реестра

Каждый официальный документ проекта должен:

- иметь уникальный идентификатор;
- иметь наименование;
- относиться к одному из типов документов;
- иметь номер версии;
- иметь статус.

Документ считается официальным только после включения в настоящий Реестр.

Изменение сведений Реестра осуществляется по решению Совета.

---

# 6. Статусы документов

Для документов используются следующие статусы:

**Draft** — документ находится в разработке.

**Review** — документ находится на рассмотрении Совета.

**Active** — документ является действующим.

**Deprecated** — документ не рекомендуется к использованию.

**Archived** — документ сохранён исключительно в архивных целях.

---

# 7. Изменение Реестра

Изменения настоящего документа принимаются Советом DigitalPerson.

Каждая новая редакция получает новый номер версии.

История изменений сохраняется в официальном репозитории проекта.

---

# Заключительные положения

Настоящий Реестр является официальным перечнем документов проекта DigitalPerson.

После публикации в официальном репозитории проекта документ приобретает статус действующего.
