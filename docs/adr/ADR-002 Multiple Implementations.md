# ADR-003 Multiple Implementations

## Status

Accepted

## Date

2026-07-27

## Context

DigitalPerson является спецификацией цифровой личности, а не проектом,
написанным на конкретном языке программирования.

Необходимо обеспечить возможность существования нескольких независимых
реализаций одной и той же спецификации.

## Decision

Все реализации располагаются в каталоге `implementation/`.

Каждая реализация является самостоятельной и должна соответствовать
спецификации, расположенной в каталоге `docs/`.

Python объявляется первой эталонной реализацией.

## Consequences

Спецификация остается независимой от языка программирования.

Новые реализации могут добавляться без изменения структуры проекта.

Документация не зависит от конкретной реализации.
