**Документ:** DOC-200-ROLE-REGISTRY

**Версия:** 1.0.0

**Статус:** Active*

> *Статус Active вступает в силу после публикации настоящего документа в официальном репозитории проекта.*

**Основание:** DOC-000-CONST v0.1.0  
**Связанный документ:** 
- DOC-000-CONST
- DOC-110-CHARTER

---

# 1. Общие положения

Настоящий документ определяет перечень официальных ролей проекта DigitalPerson.

Реестр ролей является единым источником информации о существующих ролях проекта.

Подробное описание назначения, компетенции, полномочий и порядка взаимодействия каждой роли определяется отдельным документом — Паспортом роли.

---

# 2. Назначение Реестра

Реестр ролей предназначен для:

- ведения официального перечня ролей проекта;
- обеспечения единообразной идентификации ролей;
- фиксации статуса каждой роли;
- поддержки развития организационной структуры проекта.

---

# 4. Правила ведения Реестра

Каждая роль проекта должна:

- иметь уникальный идентификатор;
- иметь уникальное наименование;
- иметь Паспорт роли;
- иметь установленный статус.

Добавление новой роли осуществляется только по решению Совета.

Изменение или исключение роли осуществляется только по решению Совета.

---

# 5. Статусы ролей

Для ролей используются следующие статусы:

**Draft** — роль находится в разработке.

**Active** — роль действует и используется в проекте.

**Deprecated** — роль не рекомендуется к использованию и ожидает вывода из эксплуатации.

**Archived** — роль выведена из состава проекта и сохранена исключительно в исторических целях.

---

# 6. Паспорта ролей

Для каждой роли создаётся отдельный документ — Паспорт роли.

Паспорт роли определяет:

- назначение;
- область ответственности;
- компетенцию;
- права;
- ограничения;
- взаимодействие с другими ролями.

---

# 7. Изменение Реестра

Изменения настоящего Реестра принимаются Советом.

Каждая новая редакция получает новый номер версии.

История изменений сохраняется в официальном репозитории проекта.

---

# Заключительные положения

Настоящий Реестр является официальным перечнем ролей проекта DigitalPerson.

После публикации в официальном репозитории проекта документ приобретает статус действующего и используется при разработке всех последующих нормативных документов проекта.
