# 1. Назначение

Настоящий документ является точкой входа в документацию раздела Foundation проекта DigitalPerson.

Раздел Foundation содержит фундаментальные документы, определяющие принципы, правила управления и терминологию проекта.

---

# 2. Структура Foundation

## Governance

Раздел содержит нормативные документы проекта:

- Конституция;
- Устав Совета;
- Реестр документов;
- Реестр ролей.

## Roles

Раздел содержит паспорта официальных ролей проекта.

Каждая роль описывается отдельным документом.

## Terminology

Раздел содержит официальный глоссарий терминов проекта.

---

# 3. Назначение раздела Foundation

Документы раздела Foundation определяют:

- фундаментальные принципы проекта;
- организационную структуру;
- систему ролей;
- правила управления;
- официальную терминологию.

Foundation не описывает внутреннюю архитектуру DigitalPerson.

---

# 4. Связанные разделы

После Foundation документация проекта развивается в следующих направлениях:

- 01_Core
- 02_Cognition
- 03_Project
- ADR
- RFC

# 5. Изменение документа

Настоящий документ поддерживается Советом DigitalPerson.

Изменения вносятся только при изменении структуры документации проекта.
