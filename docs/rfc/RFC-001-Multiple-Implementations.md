# RFC-001 Multiple Implementations

## Status

Draft

## Summary

Предлагается отделить спецификацию DigitalPerson от её реализации.

## Motivation

Архитектура проекта должна быть независима от языка программирования.

Python является первой реализацией, но не единственной возможной.

В будущем могут появиться реализации на Rust, C++ и других языках.

## Proposed Structure

implementation/

    python/

    rust/

    cpp/

## Open Questions

- Какие реализации следует считать эталонными?
- Нужно ли поддерживать полное соответствие всех реализаций?
